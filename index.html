oo-patterns

Plain HTML, modern CSS and a little vanilla JavaScript for people who show their work: designers, developers and media producers. No framework, no runtime dependencies. Every pattern below is a static page you can view source on and copy.

  • FoundationsTokens, type scale, buttons, tags and form controls.
  • HeadersSplit and centred headers with a keyboard-friendly menu toggle.
  • HeroesA statement hero and a full-bleed slider with pause control.
  • AboutPortrait, introduction, quick facts and skills.
  • ServicesFeature grid that adapts to its container width.
  • PortfolioFramed cards, overlay tiles, filtering and a lightbox.
  • Case studyA complete project detail page.
  • BlogJournal index with summaries.
  • PostLong-form article with author box and pager.
  • ResumeA CV that prints cleanly.
  • ContactContact section with form, plus the site footer.
